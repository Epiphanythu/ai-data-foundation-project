# constant 配置模块

`constant/` 集中管理项目中跨模块共享的常量，避免路径、字段名、模型参数和 LLM 配置散落在业务代码里。

## 文件说明

| 文件 | 作用 |
|---|---|
| `paths.py` | 项目根目录、数据目录、输出目录、模型路径等路径常量 |
| `columns.py` | 贷款数据、标签、建模特征等字段名常量 |
| `model.py` | 模型特征组、业务假设、策略参数等建模常量 |
| `llm.py` | LLM API Key、Base URL、模型名和默认问题配置 |

## 使用原则

- 新增跨模块路径必须放入 `paths.py`。
- 新增字段名优先放入 `columns.py`。
- 新增模型或策略参数优先放入 `model.py`。
- LLM 相关配置只放入 `llm.py` 或 `.env`，不要写死在业务脚本中。

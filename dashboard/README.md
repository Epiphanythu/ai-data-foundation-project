# dashboard 交互展示模块

`dashboard/` 是最终交互展示层，负责集成项目的表格、图表、模型结果、策略结果和 LLM 助手。

## 入口

```bash
streamlit run dashboard/app.py
```

## 职责边界

- 负责：交互展示、指标卡片、图表读取、结果筛选、LLM 助手嵌入。
- 不负责：批量生成图表，这属于 `visualization/`。
- 不负责：训练模型，这属于 `modeling/`。
- 不负责：直接生成核心统计结论，这属于 `analysis/`。

## 展示内容

- 贷款数据概览和违约率统计。
- 模型指标、SHAP、PDP 和策略模拟结果。
- 状态感知风险、动态阈值和决策追溯结果。
- LLM 自动报告和自然语言问答。
